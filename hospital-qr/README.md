# Hospital Patient Registration QR Code Assets

**Destination URL:** https://dental-patient-portal-flax.vercel.app/register

This directory contains the permanent physical QR code assets created for Apex Dental Hospital.

### One Permanent QR Code for All Patients:
- This QR code is permanent and static.
- It does not expire, has no scan limits, and requires no logins, apps, or dynamic redirection.
- Unlimited patients can scan this same physical QR code day after day.
- Scanning opens the registration form directly on the patient's smartphone.
- After submitting, patients can register family members ("Register Another Patient") or exit.

---

## File Inventory

1. **hospital-registration-qr.svg**: Vector SVG format. Infinitely scalable vector for professional printing, large banners, acrylic stands, or custom graphic design work without any pixelation.
2. **hospital-registration-qr.png**: High-Resolution PNG (2400x2400 px, 300+ DPI equivalent). Crisp standalone QR image for quick printing, badges, stickers, or digital display.
3. **hospital-standee-sign.svg**: Vector SVG format. Complete hospital reception desk sign design with hospital branding, "Scan to Register as a New Patient", 3-step instructions, and framed QR code.
4. **hospital-standee-sign.png**: High-Resolution PNG (2400x3360 px, 300 DPI A4 portrait). Ready-to-print sign image.
5. **hospital-standee-sign.html**: Self-contained printable HTML page. Double-click to open in Chrome or Edge, then press Ctrl+P to print directly to A4/Letter paper or save as PDF.

## Quick Printing Instructions

### Option 1: Instant Desktop Printing (HTML)
1. Double-click **hospital-standee-sign.html** to open it in Google Chrome or Microsoft Edge.
2. Click the **"Print Standee / Save as PDF"** button (or press Ctrl + P).
3. Set Paper Size to A4 (or Letter), orientation to Portrait, and Margins to Default or None.
4. Print directly to your office/reception printer or choose "Save as PDF".

### Option 2: Professional / Acrylic Standee Printing (SVG / PNG)
1. Send **hospital-standee-sign.svg** (or **hospital-standee-sign.png**) to your print vendor or print it on heavy cardstock (250-300 gsm).
2. Insert into standard A4 or A5 clear acrylic counter-top display stands at:
   - Hospital main entrance
   - Reception and billing counters
   - Waiting room tables
